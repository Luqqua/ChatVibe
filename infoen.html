Understanding the Analysis and Values

Our Twitch Chat Analysis Tool observes the chat and identifies notable moments based on the following settings:

  • Observation Interval: The period in which activity changes are recorded (recommended: 60 seconds).
  • Activity Deviation from Average: How much the current comment count must exceed the average (e.g., a factor of 2 = twice as many comments).
  • Detection Mode: Determines how a highlight is detected. In OR mode, a highlight is detected if either a deviation from the previous interval or a deviation from the average is present. In AND mode, a highlight is only detected if both conditions are met.
  • Activity Deviation from Previous Interval: The difference in the number of messages between consecutive intervals (e.g., +10 messages).

KPIs (Key Performance Indicators)

  • Activity Score (Messages per minute): Measures how many messages are sent per minute.
  • Diversity Score (Message distribution among chatters): Indicates how evenly messages are distributed among chat participants (1 = evenly distributed, 0 = dominated by a few users).
  • Average Length: The average number of characters per message.
  • Chat Engagement Index: A weighted summary of the above KPIs, calculated as:
    0.6 × (Activity Score / 294) + 0.3 × (Diversity Score) + 0.1 × (Average Length / 30).
    Here, 294 (messages per minute) and 30 (characters) are median benchmarks from the top 100 streamers. An index of 1 represents typical engagement for a top streamer.

Requirements & File Formats

To run the tool, a CSV or JSON file containing chat logs is needed. We directly support the formats from twitchchatdownloader.com and TwitchDownloader on GitHub. Chat logs can be downloaded directly from these sources. Alternatively, CSV or JSON files that meet the following requirements can be used. This also allows the use of chats from other platforms that are not from Twitch.

CSV File:
Must contain at least three columns with the following headers (in lowercase and with underscores):

  • time – Seconds since the start of the stream (numeric value)
  • user_name – Name of the chat user
  • message– Content of the chat message

JSON File:
Must contain a field comments, whose value is an array. Each element in this array is an object and must have the following fields:

  • content_offset_seconds – Seconds since the start of the stream
  • commenter.display_name – Display name of the user
  • message.body – Content of the chat message

If these fields are missing, the file cannot be analyzed.

What Is the Analysis Suitable For?

This tool quickly locates chat highlights without having to sift through the entire log. Interesting points can then be checked in the VOD to identify active phases, peak times, or frequently mentioned topics and keywords.

  • Mark highlights in the chat and review them later in the VOD.
  • Identify active phases and peak times at a glance.
  • Filter out frequently mentioned topics and keywords.
  • Track KPIs such as activity and diversity of comments.

The insights gained help optimize content and streaming strategies and can be used cross-platform — for example, to create TikTok highlights. The tool is also a practical aid for research, marketing or in-depth analyses of Twitch communities.
